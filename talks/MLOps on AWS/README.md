# MLOps on AWS: a Hands-On Tutorial

MLOps advice is often either too abstract to act on or too tool-specific to generalise. This hands-on tutorial fixes that by walking through implementing MLOps directly on AWS — experiment tracking and model registries included — with attendees building the pipeline alongside the talk.

Attendees leave with a working AWS MLOps setup they built themselves, not just slides describing one.

## Where it was held

- Applied Machine Learning Days (AMLD), Lausanne, Switzerland, 2022

# From Embeddings to Transformers: Build Your Own GPT

Understanding transformers by reading about them only gets you so far — building one does more. This hands-on workshop starts from tokenization and embeddings and walks through assembling a simplified generative language model from scratch.

Attendees leave having built and trained a working (if small) GPT-style model themselves, with a much more concrete mental model of what's actually happening inside an LLM.

## Where it was held

- Applied Machine Learning Days (AMLD) — "At the Cutting Edge of Generative AI", Lausanne, Switzerland, 2024

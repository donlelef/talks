# How to Behave in a Team? Heuristics from Game Theory

Team dynamics look a lot like an iterated prisoner's dilemma once you squint: everyone benefits from cooperation, but everyone's individually tempted to defect. This talk applies game theory research to real team situations — code review, credit-sharing, conflict — to extract heuristics for better collaboration.

Attendees leave with concrete, research-backed heuristics for how to behave in a team that improve outcomes for the group without requiring anyone to be a saint.

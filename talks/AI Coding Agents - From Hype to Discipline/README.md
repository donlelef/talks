# AI Coding Agents: From Hype to Discipline

AI coding agents promise to accelerate development, but without discipline they can amplify problems we already know well: improvised design, hard-to-maintain code, insufficient testing, excessive permissions, and even production incidents.

This talk uses real cases and recurring anti-patterns to examine where AI-assisted development fails, and how to design safer, verifiable workflows around it. We'll cover concrete practices — sandboxing, access policies, harness engineering, automated testing, and spec-driven development — and confront the fear of becoming obsolete with recent data and research: AI doesn't eliminate the need for engineering skill, it shifts the value toward design, validation, review, and system governance. The goal is to leave with a practical checklist for using coding agents productively, without turning the repository into an uncontrolled experiment.

# Heuristics for Code Review

Code review is where a lot of engineering time disappears without a clear return. This talk shares practical heuristics — what to look for, what to skip, how to give feedback — that make code review faster without making it worse.

Attendees leave with a set of heuristics they can apply the next time they open a pull request, cutting review time without cutting review quality.

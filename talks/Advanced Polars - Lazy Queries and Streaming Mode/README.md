# Advanced Polars: Lazy Queries and Streaming Mode

Polars' lazy execution engine and streaming mode let you process datasets far larger than memory — if you know how to use them. This talk digs into how lazy queries are planned and optimised, and how streaming mode changes the way you should write data pipelines.

Attendees leave with practical techniques to push Polars pipelines past the limits of what fits in RAM, without rewriting everything in a distributed framework.

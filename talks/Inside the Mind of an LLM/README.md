# Inside the Mind of an LLM

Interpretability research has made real progress on a question that used to be unanswerable: what is actually happening inside an LLM? This talk tours recent breakthroughs — English as an internal pivot language in Llama 2, monosemantic features in Claude 3 and GPT-4, why LLMs memorise outlier data — and explains them without requiring a research background.

It's a talk built for engineers who use LLMs daily but have never had a clear picture of what's happening under the hood. Attendees leave with a mental model of LLM internals that makes prompting, fine-tuning, and debugging model behaviour noticeably more intuitive.

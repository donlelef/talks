# Evaluating GenAI Applications

"It looks good in the demo" is not an evaluation strategy. This talk lays out a practical framework for evaluating GenAI applications both before and after they reach production, covering what to measure, how, and how often.

Attendees leave with a concrete evaluation checklist they can apply to their own GenAI application instead of relying on gut feel.

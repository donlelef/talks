# From Chickens to Transformers: The Rise of Foundation Models in Forecasting

Forecasting has quietly gone through the same evolution NLP did: from hand-built heuristics to large pre-trained foundation models. This talk traces that arc and unpacks what transformer-based foundation models change about how forecasting systems get built.

Attendees leave with a framework for deciding when a foundation model is worth adopting for a forecasting problem, and when a simpler classical approach still wins.

# Serverless Computing for Mathematical Optimization

Mathematical optimization problems are usually treated as inherently slow and stateful — a poor fit for serverless. This talk is a case study that overturns that assumption, showing how cloud functions cut an optimization problem's solve time by 96%.

Attendees leave with a concrete pattern for parallelising optimization workloads on serverless infrastructure, backed by real numbers rather than a theoretical argument.

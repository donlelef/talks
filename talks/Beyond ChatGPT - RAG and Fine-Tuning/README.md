# Beyond ChatGPT: RAG and Fine-Tuning

ChatGPT is a great generalist, but most real applications need an LLM that knows your data. This talk examines Retrieval Augmented Generation and fine-tuning as complementary techniques for grounding LLMs in domain-specific knowledge, with a clear-eyed look at when to use which.

Attendees leave able to decide, for their own use case, whether RAG, fine-tuning, or a mix of both is the right tool — instead of defaulting to whichever they read about last.

# Angels and Demons

AI agents in production are a double-edged sword: the same autonomy that makes them useful is what makes them dangerous when they go wrong. This talk explores that tension through concrete failure modes and the guardrails that keep agents on the "angel" side of the line.

Attendees leave with a practical checklist for deciding how much autonomy to grant an agent — and what to put in place before they do.
